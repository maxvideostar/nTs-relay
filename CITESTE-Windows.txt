StreamHub pentru Windows 10 / 11 (64-bit)
==========================================

1. Pune streamhub.exe într-un folder fix, de exemplu C:\StreamHub
2. Dublu-click pe streamhub.exe
   - prima dată creează config.json lângă exe (parola de admin apare în fereastră)
   - se deschide singur panoul în browser: http://127.0.0.1:8000/
   - Windows întreabă de Firewall -> Permite accesul (rețele private și publice)
3. Adaugă canale din panou (+ Canal).

Pornire automată odată cu Windows (fără fereastră deschisă):
   închide fereastra StreamHub, apoi într-un cmd în folderul aplicației:
      streamhub.exe -install
   (cere drepturi de Administrator; adaugă și regula de firewall)
   Oprire definitivă:  streamhub.exe -uninstall

Jurnal:  streamhub.log  (în același folder)
Config:  config.json    (port, parolă, tokeni, canale)

SRT și RTMP au nevoie de ffmpeg.exe: descarcă-l (ex. de pe gyan.dev,
"ffmpeg-release-essentials") și pune ffmpeg.exe în același folder cu streamhub.exe.
UDP, RTP, HTTP și HLS merg fără ffmpeg.

Linkuri de ieșire (înlocuiește IP-ul și ID-ul canalului):
   http://IP:8000/play/<id>?token=<token>
   http://IP:8000/hls/<id>/index.m3u8?token=<token>
